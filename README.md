# tasteskill para low-code

A [tasteskill](https://github.com/Leonxlnx/taste-skill) de Leonxlnx, adaptada para
desenvolvimento em plataformas low-code, principalmente o **Mendix**.

```bash
npx skills add ljacomi/taste-skill-for-low-code-
```

- **Não muda:** a estrutura de visualização e o bom gosto de design da skill original.
- **Muda:** a criação. Nada de UX em hard code (HTML, CSS, React, Tailwind). As telas são feitas
  com itens modulares da plataforma (tema, design properties, layouts, page templates, building
  blocks, snippets, widgets) e os dados com o domain model.

A skill é um único arquivo: [`skills/taste-skill-low-code/SKILL.md`](skills/taste-skill-low-code/SKILL.md).
